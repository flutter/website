# Cloud Firestore persistence example

Source for the
[Persist data with Cloud Firestore](https://docs.flutter.dev/cookbook/persistence/firestore)
cookbook recipe.

`lib/firebase_options.dart` contains placeholder values so that the
example compiles in CI. To run the app against a real Firebase project,
install the FlutterFire CLI and regenerate the file:

```console
$ dart pub global activate flutterfire_cli
$ flutterfire configure
```
